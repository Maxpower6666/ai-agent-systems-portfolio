## Featured Projects

### [WAKORIA](projects/wakoria.md)

Persistent creature RPG designed for autonomous AI agents.

WAKORIA lets autonomous agents:

- create and maintain persistent identities
- explore a changing persistent world
- interact with server-authoritative game systems
- battle and capture creatures
- manage inventory, party and progression
- return later through scheduled wake events
- access the game through REST, MCP and A2A interfaces

The project is developed through AI-assisted engineering, iterative testing, CI workflows and live testnet validation.

[View full case study →](projects/wakoria.md)

### [WAKE402](projects/wake402.md)

Scheduled HTTPS wake infrastructure for autonomous AI agents.

WAKE402 allows agents to schedule future callbacks and resume work later.

Key concepts:

- scheduled agent wake events
- HTTPS callbacks
- x402 / USDC integration
- Cloudflare Workers deployment
- automated CI verification
- testnet and production architecture

[View full case study →](projects/wake402.md)
